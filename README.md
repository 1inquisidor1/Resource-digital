# 📚 Índice Maestro de Documentación: Resource Digital

Bienvenido a la base de conocimientos técnica de **Resource Digital**. Este proyecto está construido sobre una arquitectura de **18 Sistemas Atómicos** para garantizar la escalabilidad DePIN.

**Estado Actual:** v5.1 ALPHA (Pre-Beta Infraestructura Core)
**Mercado Inicial:** Ecuador (EC)

## 🏗️ Arquitectura Core (Sistemas 1-9)
Estos sistemas forman el motor operativo del nodo en el dispositivo del usuario.

- [**S00: Visión General**](docs/00-vision-general.md) - Concepto, propuesta de valor y modelo de negocio.
- [**S01: App UI**](docs/S01_ui.md) - Interfaz de usuario, onboarding y experiencia de usuario.
- [**S02: Servicio & Overlay**](docs/S02_service.md) - Gestión de primer plano y persistencia del nodo.
- [**S03: Captura de Sensores**](docs/S03_sensors.md) - Recolección de datos ambientales y anonimización.
- [**S04: Buffer Local**](docs/S04_buffer.md) - Almacenamiento SQLite WAL y rotación de datos.
- [**S05: SDK de Banda**](docs/06-registro-honeygain-publisher.md) - Integración de monetización de ancho de banda (Honeygain, Pawns, Bright).
- [**S06: Capa peaq**](docs/S06_peaq.md) - Identidad DID y verificación on-chain.
- [**S07: Boosters & Reparto**](docs/S07_boosters.md) - Algoritmos de multiplicadores y reparto 70/30.
- [**S08: Panel de Recursos**](docs/S08_panel.md) - Transparencia de consumo y ganancias.
- [**S09: Afiliados v2.0**](docs/S09_affiliates.md) - Sistema de referidos multinivel.
