# Stack Tecnológico Definitivo

## 📱 Frontend & Mobile
- **Framework:** Flutter 3.47.4 / Dart 3.13.3
- **IDE:** Android Studio / VS Code
- **JDK:** OpenJDK 26.0.2.1
- **Android SDK:** API 36 / Build-tools 37.0.0
- **Estado:** Riverpod 2.6.1 / go_router 14.6.2

## ⚙️ Backend & Infraestructura
- **Backend:** Supabase (PostgreSQL 15+)
- **Auth:** Supabase Auth (JWT)
- **Edge Functions:** Deno
- **Monitoreo:** Sentry + UptimeRobot
- **Analytics:** PostHog + Metabase

## ⛓️ Capa DePIN & Blockchain
- **L1 Blockchain:** peaq
- **Identidad:** peaq ID (DID)
- **Pagos:** peaq pay + PayOS (USDC $ightarrow$ PIX/SPEI)
- **Almacenamiento:** DeNet (Watcher Node)
- **Cómputo:** Acurast (Processor Lite)

## 🔌 SDKs & Librerías Clave
- **Banda:** Pawns.app / Honeygain SDK
- **Servicio:** `flutter_background_service`
- **Overlay:** `flutter_overlay_window`
- **Seguridad:** `flutter_rasp` + `flutter_secure_storage`
- **Sensores:** `sensors_plus`
